# 企业微信管理工具

> Phase 0 产物：想法捕获

## 一句话描述

做一个 Web 后台，帮公司 IT 管理员统一管理企业微信的配置、通讯录和消息推送，不用每次登录企微管理后台找功能。

## 想法草稿

我们公司用了企业微信，但管理比较散。配置应用、看组织架构、给部门发通知，都要在企业微信管理后台里操作，界面复杂，IT 同事也不太熟悉。

我想做一个自己的 Web 管理工具，能连上企业微信 API，把通讯录同步过来展示成树形结构，能搜员工，还能从网页上给指定的人或部门发应用消息。先给内部几个管理员用，不用做得很复杂，能跑起来就行。

以后可能还要加客户联系、审批之类的，但第一版不需要。

## 关键词

- 用户：公司 IT 管理员、行政人员
- 场景：配置企微、查看组织架构、批量发通知
- 核心价值：一个简洁的自有后台，聚合常用企微管理操作

## 初步直觉

- 可能需要的功能：
  - 企业微信 API 对接（corpId、secret 等配置）
  - 通讯录同步（部门 + 成员）
  - 部门树、成员列表、搜索
  - 发送应用消息（文本）
  - 管理员登录
- 可能不需要的功能：
  - 客户联系（外部联系人）
  - 审批、打卡、汇报
  - 移动端 App
  - 多企业 SaaS 多租户
- 技术偏好（如有）：
  - 熟悉 TypeScript
  - 希望前后端一体，部署简单
