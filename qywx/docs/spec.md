# 企业微信管理工具 — 需求规格

> Phase 1 产物：需求规格（Spec）

## 一句话描述

为单企业 IT 管理员提供 Web 后台，完成企微应用配置、通讯录同步展示、成员搜索及文本应用消息发送。

## 用户场景

1. 作为 **IT 管理员**，我想 **在网页上配置企业微信 corpId 和 Secret**，以便 **系统能调用企微 API**。
2. 作为 **IT 管理员**，我想 **一键同步通讯录到系统**，以便 **在自有界面查看组织架构而不登录企微后台**。
3. 作为 **行政人员**，我想 **按部门浏览成员并搜索姓名**，以便 **快速找到要通知的人**。
4. 作为 **IT 管理员**，我想 **向选定成员或整个部门发送文本通知**，以便 **从统一入口群发消息**。
5. 作为 **IT 管理员**，我想 **查看历史发送记录和同步日志**，以便 **排查问题**。

## MVP 功能清单（P0）

- [ ] **F1** 管理员登录 / 登出（本地账号）
- [ ] **F2** 企微应用凭证配置（corpId、agentId、secret），Secret 加密存储
- [ ] **F3** 手动触发通讯录全量同步（部门 + 成员）
- [ ] **F4** 部门树形展示（支持展开/折叠）
- [ ] **F5** 成员列表（按部门筛选、姓名/工号搜索、分页）
- [ ] **F6** 发送文本应用消息（选人 / 选部门，支持多选）
- [ ] **F7** 发送记录列表（时间、内容摘要、目标、状态）
- [ ] **F8** 同步日志（时间、结果、耗时、错误信息）

## 明确不做（v1）

- 客户联系（外部联系人）管理
- 审批、打卡、汇报、日程
- 图文 / 图片 / 文件消息（仅文本）
- 消息模板 CRUD
- 多企业 / 多 corpId 多租户
- 企微扫码 OAuth 登录（管理员用本地账号）
- 细粒度 RBAC（第一版所有管理员同等权限）
- 移动端适配（仅桌面 Web）

## 技术约束

| 项 | 说明 |
|----|------|
| 前端 | React，桌面 Web，现代浏览器 |
| 后端 | Node.js，与前端同仓库 |
| 数据库 | 关系型数据库（开发可用 SQLite，生产 PostgreSQL） |
| 部署 | 公司内网单机，Docker 可选 |
| 已有系统对接 | 企业微信开放平台 API（通讯录、应用消息） |

## 非功能要求

| 项 | 要求 |
|----|------|
| 性能 | 成员列表首屏 < 1s（500 人规模，读本地 DB）；同步 500 人 < 60s |
| 安全 | Secret 加密存储；管理接口需登录；生产环境 HTTPS |
| 可用性 | 同步失败有明确错误提示；发送失败可查看原因 |
| 其他 | 操作日志保留 90 天 |

## 完成标准（验收）

- [ ] `docker compose up` 或等价命令可本地启动
- [ ] 管理员可登录并配置企微凭证
- [ ] 点击同步后，部门树与成员列表与企微后台一致（允许短暂延迟）
- [ ] 可向 1 名成员和 1 个部门成功发送文本消息，成员企微客户端能收到
- [ ] 发送记录与同步日志可查询
- [ ] 未登录访问 API 返回 401
